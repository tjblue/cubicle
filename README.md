# CLI Viewer

Dockview Desktop is a Tauri workspace for terminal, file, and browser panes.

## Development

Install Node.js, Rust, and the Tauri Windows prerequisites, then run from this folder:

```powershell
npm install
npm run desktop:dev
```

Run `npm run dev` for the browser interface or `npm run desktop:build` to build the desktop application. See [space profiles](docs/guides/space-profiles.md) for profile configuration and [the recovered app guide](docs/recovered-app-readme.md) for feature details (its old file paths may be outdated).
