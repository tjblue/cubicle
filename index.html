Profile options and examples

Minimal: {"name":"My space"}. Add root for the project folder, direction as row or column, and a panes array. A pane can be "terminal", "files", "browser", or an object with a type. Use {"tabs":[...]} to put tools in one pane.

Terminal options: title, cwd, shell, env (object), command. Browser: url, favorites (name/url objects). Files: root, pins (name/path objects), reveal (file path). ${workspace} in paths resolves to the space folder. Commands run only when launching a profile, after confirmation; they do not rerun when a space is restored.
